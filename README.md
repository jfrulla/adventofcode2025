# Advent of Code 2025

None of this is AI, nor is it overly influenced by anything other than verifying "idiomatic" ways of formulating the logic via GoByExample (in most cases). This is a real attempt to do this straight-off-the-dome, or with a few suggestions from friends and colleagues.

To compile and run, simply install golang 1.23.5+, cd to one of the individual day directories and run

```
go build name_of_program.go
```

Then execute the binary while inside of that directory (I use relative paths for the input files in most/all cases).
